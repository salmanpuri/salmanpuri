## Featured case study: Filly AI

**AI-assisted reservation automation for Limo Anywhere**

Filly is a browser-based reservation automation system I designed and developed with AI-assisted coding tools. It interprets unstructured reservation requests and works through the Limo Anywhere reservation interface.

My work includes:

- Designing workflows to extract booking information from emails, notes, and documents.
- Handling passengers, bookers, pickup and drop-off locations, and flight details.
- Testing dynamic browser forms, autocomplete fields, and multi-step reservation flows.
- Checking extracted data for missing information, incorrect assumptions, and invented trip details.
- Reproducing failures such as incorrect vehicle selection or missing passenger information.
- Verifying that intended actions actually completed and detecting regressions after changes.
- Improving recovery from changing UI states and incorporating human review.

This work connects business requirements with practical agent evaluation: correct data, correct actions, clear failure reporting, and appropriate escalation.

## How I work

- **Business analysis:** translate operational needs into requirements, workflow steps, and acceptance criteria.
- **Agent evaluation:** assess instruction-following, data accuracy, task completion, and error recovery.
- **Quality assurance:** reproduce failures, document expected versus actual behavior, and retest after changes.
- **Human-in-the-loop design:** identify ambiguity and points that require review before proceeding.
- **Operational validation:** check whether a workflow meets the business need, beyond whether a UI action appears successful.
